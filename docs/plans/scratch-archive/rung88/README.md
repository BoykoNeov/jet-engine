# Rung 88 scratch scripts

Kept so the givens and the scoring in `docs/rung88-spec.md` can be re-run. Each is a scratch-crate binary (path dependency on `rust/`): `probe.rs` the anchor's section 0 givens (args p0-p4: the reduces and entry points, the start positions and slopes, the lagged phi valve beside the stators, the 21 tabulated cells with the lag identity, rung 65's own case and the matcher's monotone curve); `score.rs` every H bar (arg: ds); `equal_requirement.rs` the spec's section 4 table, both slow valves re-tuned to rung 87's margin, with the minima's place, the lag there, saturation and clamp counts (arg: ds); `page_step.rs` the sandbox's step check behind the slow valve's one-step floor (plan section 17); `crash_slow_valve.rs` the sandbox crash map with every request the slow valve.
