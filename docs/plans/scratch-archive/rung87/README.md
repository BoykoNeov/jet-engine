# Rung 87 scratch scripts

Kept so the givens and the scoring in `docs/rung87-spec.md` section 3 can be re-run. Each is a scratch-crate binary (path dependency on `rust/`): `probe.rs` the anchor's section 0 givens (args p1-p4: the builder trap, the ceilings, the phi valve's set points, the phi valve beside the phi fuel floor); `score.rs` every H bar (args: ds, then h = H1-H4 with the matched phi valve, f = H5 and D4); `crash_valve.rs` the sandbox crash map with every request the controlled valve (plan section 16).
