# Rung 86 scratch scripts

Kept so the scoring in `docs/rung86-spec.md` section 3 can be re-run. `score_cube.rs` is the scratch crate main (path dependency on `rust/`; arg a|b|c = accel / turbine limiter / floors), printing every cube at both steps; `score_c.py` and `c3split.py` score the floor bars from its output; `crash_both_levers.rs` is the section 14.3 crash map with every request on both levers (sandbox plan section 15).
