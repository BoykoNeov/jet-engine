
Two-spool + component maps (rung 39): rung 38 predicted a map would force a joint 2x2
solve. It does not. pi_LPC CANCELS out of the HP compressor's corrected flow, so the map
opens EXACTLY ONE arrow (HP -> LP): the cascade acquires a DIRECTION instead of dissolving.

  THE FINDING — perturb one efficiency by -0.01 at fixed (Tt2, pt2, Tt4=1200, f);
  compressor maps only (a_t = 0), so the reading is the pure structural one:
   parameter   d pi_LPC / pi   d pi_HPC / pi  channel
  --------------------------------------------------------------------------
     eta_LPC      -9.128e-03       EXACTLY 0  own ratio only -- CANNOT reach pi_HPC (pi_LPC cancels)
     eta_HPC      -5.648e-04      -1.456e-02  own ratio AND pi_LPC -- THE ONE ARROW the map opens
     eta_HPT      +1.261e-03      -1.634e-02  energy path: moves BOTH (shapes the shared Tt45)
     eta_LPT      -9.265e-03      +3.357e-03  energy path: moves BOTH (shapes Tt25 via Tt5)
  eta_LPC -> pi_HPC is EXACTLY zero (bit-for-bit), by the (dagger) cancellation -- while
  eta_HPC -> pi_LPC is real and negative. ONE arrow, not two: still strictly triangular.

  Both shaft works are eta_m*(1+f)*cp_t*Tt4*[pure geometry], so (1+f) AND Tt4 cancel in
  N_L/N_H: on CPG + flat maps the slip is EXACTLY 1 at every throttle. The cp(T) gas curve

  ON CPG that INVERTS rung 32 (where the map only re-labelled map-free work): the deviation is

  NOT unconditional -- on the reacting gas the same FLAT maps already give 0.9835 at Tt4=900,
